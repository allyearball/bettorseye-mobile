# The bettorseye phone apps

The iPhone and Android apps are bettorseye.com inside a native shell, built with Capacitor 8.

The shell adds `BettorsEyeApp` to the browser's name. The site sees that (`eyIsApp()` in eye.js,
`IN_APP` in the sign-in shell, `inApp` in landing.html) and becomes sign-in only:
- no landing page and no request-access form;
- no plans, prices, trial or checkout;
- no sportsbook links, and no install tip or web alerts;
- always the new layout.

`apptest.js` checks all of it. Because the app loads the live site, **a site deploy updates the app
too**. A new store build is needed only when something in this folder changes.

## What's here
- `capacitor.config.json`: app id `com.bettorseye.app` and the address it opens
  (`https://bettorseye.com/?app=1`), plus the offline page, splash and status bar.
- `android/`, `ios/`: the native projects (generated by `npx cap add`; the iOS one uses Swift
  Package Manager, so no CocoaPods).
- `resources/`: the source icon and splash. They're drawn by `make_icons.js` in the main folder.
  `npm run icons` turns them into every size.
- `www/`: the offline page, and a fallback page that forwards to the site.
- `.github/workflows/mobile.yml`: builds both apps on GitHub, including the iPhone build, on Apple's
  Macs.
- `STORE_LISTING.md`: everything to type into App Store Connect and Play Console.

## One-time setup (in this order)
1. **GitHub.** Create an empty **private** repo named `bettorseye-mobile`. Claude pushes this folder
   to it.
2. **Android upload key.**
   - Go to Actions > mobile > Run workflow, tick only `make_upload_key`, and run it.
   - Download the `android-upload-key` artifact, then delete the artifact on the run page.
   - Save its three .txt values as repo secrets (Settings > Secrets and variables > Actions):
     `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`.
   - Keep `upload.keystore` and its password in a password manager.
3. **Apple.**
   - Once the developer membership is active, register the bundle id `com.bettorseye.app`
     (Certificates, IDs & Profiles > Identifiers > +).
   - In App Store Connect, create the app with that bundle id.
   - Make an API key: Users and Access > Integrations > App Store Connect API > +, with **App Manager**
     access. Download the .p8 file; it downloads once only.
   - Add these secrets:
     - `APPSTORE_KEY_ID` (the key's id);
     - `APPSTORE_ISSUER_ID` (shown above the keys);
     - `APPSTORE_KEY_P8_BASE64`: the .p8 file in base64. In PowerShell:
       `[Convert]::ToBase64String([IO.File]::ReadAllBytes("AuthKey_XXXX.p8")) | Set-Clipboard`;
     - `APPLE_TEAM_ID` (Membership details > Team ID).
4. **Google Play.** Create the app in Play Console (free, app, not a game).

## Each release
- Run the workflow with `android` and `ios` ticked.
- The **iPhone build uploads itself** to App Store Connect. It appears under TestFlight in 5 to 30
  minutes; then submit it for review.
- The **Android build** is an .aab on the run page. Upload it in Play Console, to the closed testing
  track first (see the 12-tester rule in STORE_LISTING.md).
- Build numbers come from the run number, so each run is newer than the last.
